DETAILED IMPLEMENTATION PROMPT — POLICE DISPATCH AND PURSUIT AI

Extend the police system into a complete fictional gameplay simulation.

DISPATCH
Police incidents are generated by game events. Dispatch assigns available units based on incident severity, district, unit distance, road access, and current workload. Use clear radio-style fictional audio and UI status.

UNIT TYPES
Foot patrol, standard patrol car, highway patrol, motorcycle unit, specialist response, and helicopter support only where the game world and platform budgets justify them.

SEARCH AND PURSUIT
Units navigate using the road graph, pursue using vehicle handling limits, coordinate search zones, investigate last known locations, and communicate state changes. Avoid teleporting units, impossible turns, or perfect knowledge of the player.

ESCALATION
Wanted level depends on witnessed game events and mission state. Define clear thresholds for additional response. Give the player readable feedback and fair opportunities to evade or surrender.

ARREST FLOW
Define surrender, restraint animation, processing, jail transition, fines, temporary confiscation, release, and return to free roam. Ensure the player cannot become permanently stuck.

PERFORMANCE
Use unit caps, spawn distance rules, simulation LOD, simplified distant pursuit, and careful navigation updates. Never spawn a police unit directly in the player's view unless a scripted mission explicitly calls for it.

QA
Test dispatch overload, traffic congestion, pursuit across district boundaries, loss of sight, search timeout, arrest, mission conflict, save/load, and mobile performance.
